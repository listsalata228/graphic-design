# Задание: Графический интерфейс пользователя

## Описание проекта

Репозиторий содержит три учебных приложения, разработанных на языке Python с использованием графического интерфейса:

Калькулятор -  для выполнения арифметических операций с валидацией ввода и обработкой ошибок.

Формы учёта-отчёта - для добавления и редактирования данных пациентов, расчёта ИМТ и построения статистических графиков.

Урезанный FastQС - для проверки и анализа файлов FASTQ.

## Используемые технологии

Python 3

Tkinter — создание графического интерфейса

ttk — дополнительные элементы интерфейса

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/listsalata228/graphic-design.git
```

### 2. Переход в папку проекта

```bash
cd graphic-design
```

### 3. Cоздание виртуального окружения

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 4. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 5. Запуск приложения

Для запуска каждого задания необходимо выполнить соответствующий Python-файл:
Калькулятор 
```bash
python my_calculator2.py
```

Названия файлов и точные команды запуска будут уточнены после завершения разработки всех трех приложений.
